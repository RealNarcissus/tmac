# tmac 0.2.0 — first public release

**Terminal-first, MCP-controllable macOS VM control plane for Linux.**

## Highlights

- Attach an already-running QEMU/Reims VM by QMP socket: `tmac attach`.
- MCP over stdio with 8 tools: screenshot, click, move, drag, scroll, type, key, status.
- External VMs remain owned by their hypervisor; `tmac start/stop` refuse lifecycle changes.
- Preserved macOS Monterey QEMU/QMP workflow and Linux terminal viewer.
- Reproducible Tahoe 26.6.2 / Reims vGPU evidence at 1024×768.
- Packaging, CI, issue/PR templates, security and legal notices.

## Install

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install 'tmac-linux[mcp]'   # once published to PyPI; otherwise install from this repo
tmac --help
```

The GitHub release wheel is built from this tag. The CLI and project are named `tmac`; the Python
distribution is `tmac-linux` because `tmac` is already used on PyPI.

## Known limits

- Tahoe at 1024×768 on the tested 4 GiB GPU; higher modes can exhaust host Vulkan memory.
- The MCP surface is GUI computer use; app build/test CI is not yet demonstrated.
- x86_64 macOS only; Apple-silicon parity is out of scope.
- Apple licensing and third-party licenses require review before commercial or hosted use.
- macOS, installers, VM disks, OSK, and Apple binaries are not included.
